# 反馈处理流程

## 反馈入口

- GitHub Issues：https://github.com/lisong2003-lgtm/skill-architect/issues
- SkillHub / Coze 用户评价
- 用户在使用 Skill Architect 时直接反馈

## 查看反馈

1. 打开 GitHub Issues。
2. 按标签筛选：
   - `bug`：功能异常或脚本报错。
   - `feature`：新能力建议。
   - `documentation`：说明不清楚。
   - `question`：使用疑问。
3. SkillHub / Coze 后台查看评价和评论。

## 反馈分类

| 类型 | 示例 | 处理优先级 |
| --- | --- | --- |
| 严重 Bug | 脚本无法运行、数据丢失、隐私泄露 | P0 |
| 普通 Bug | 某个平台不兼容、文档路径错误 | P1 |
| 使用问题 | 触发语不生效、不知道如何导入 | P1 |
| 新功能 | 希望支持新的 Agent 或平台 | P2 |
| 文档改进 | 说明不清晰、缺少案例 | P2 |

## 处理步骤

1. 复现问题。
2. 定位根因。
3. 修复代码或文档。
4. 运行：

```bash
python3 scripts/self_test.py
python3 scripts/check_privacy.py --root .
```

5. 更新 `CHANGELOG.md`。
6. 行为有变化时升级版本号。
7. 重新打包并发布 GitHub Release。
8. 同步更新 SkillHub / Coze。

## 反馈闭环

- 每个已修复问题在 Release Notes 中注明。
- 说明影响范围、验证结果和遗留风险。
- 用户反馈再次出现时，按相同流程重新处理。
