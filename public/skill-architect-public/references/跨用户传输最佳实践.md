# 跨用户传输最佳实践

## 核心原则

- 只传输快照、路由索引和技能包，不传输完整对话原文。
- 先检查快照中不包含个人路径、私人聊天记录或原始书籍。
- 接收方导入后，按当前话题加载对应技能包，不读取完整旧对话。

## 发送方

在快照目录执行：

```bash
python3 scripts/export_conversation_handoff.py --snapshot-dir conversation-output --output skill-architect-handoff.zip
```

生成一个很小的 zip，包含：

- `conversation-snapshot.md`
- `routing-index.md`
- `skills/*/SKILL.md`

然后通过 Git、AirDrop、局域网共享、云盘或任意网络连接发送这个 zip。

## 接收方

在当前已开对话中执行：

```bash
python3 scripts/import_conversation_handoff.py --source skill-architect-handoff.zip --dest imported-conversation-output --topic <问题>
```

然后向当前 Agent 说：

```text
读取 imported-conversation-output/conversation-snapshot.md 和 routing-index.md，继续讨论 <问题>。
```

## 注意

- 如果发送原始 transcript，会暴露完整对话并增加传输和 Token 成本；默认不发送。
- 接收方仍需对 zip 内容做隐私检查。
- 传输方式是平台能力，Skill Architect 只负责生成和接收便携包。
