# 反馈闭环

## 适用场景

- 用户纠正了选簇或技能选择。
- 需要复盘哪些触发词漏配或误配。
- 需要把真实纠正回写配置。

## 核心方法

- 从学习日志提取用户追问/纠正。
- 生成反馈候选清单。
- 人工复核哪些是路由反馈。
- 更新 trigger/exclude。
- 重建路由索引并跑准确率测试。

## 边界

- 输出风格纠正不一定改路由触发词。
- 不自动把用户确认当成删除授权。
- 反馈日志纳入学习复盘。
