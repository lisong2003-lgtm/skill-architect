## GitHub 发布步骤

1. 在 GitHub 创建公开仓库，例如 `skill-architect`。
2. 将本目录推送为仓库根目录。
3. 保留：
   - `README.md`
   - `docs/产品说明.md`
   - `docs/使用说明.md`
   - `public/skill-architect-public-0.2.0.zip`
   - `public/skill-architect-generic-0.2.0.zip`
   - `plugins/skill-architect/`
   - `.agents/plugins/marketplace.json`
4. 在 GitHub Releases 中上传两个 0.2.0 zip，并附上 SHA-256。

## 扣子 / Coze

- 登录扣子后创建“技能”项目。
- 将 `public/skill-architect-public/` 或 `public/skill-architect-generic/` 作为技能目录。
- 按平台要求打包并部署。
- 付费版本需先开通收款账户；第一版建议免费。
