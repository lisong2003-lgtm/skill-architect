# 技能路由索引

## 适用场景

- 技能包很多，目录和技能不对应。
- 需要按问题先选簇，再按需读取技能包。
- 需要新增书后自动重建索引。

## 核心方法

- 扫描技能包目录。
- 根据触发词和排除词匹配能力簇。
- 自动生成路由索引。
- 用 test-prompts 的 expected_clusters 做准确率门槛。
- 校验技能包路径和原书路径存在。

## 边界

- 索引由脚本生成，不手工维护。
- 同一技能可进入多个簇。
- 无映射时走 N1/N9/N14/N18 基础补位。
- 路由失败写入反馈日志。
