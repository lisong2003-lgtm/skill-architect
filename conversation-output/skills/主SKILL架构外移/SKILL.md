# 主SKILL架构外移

## 适用场景

- 大 SKILL.md 每次都要全量读取。
- 需要把逐书判断尺、方法网络、素材来源等大块内容外移。
- 需要保留身份和核心判断尺，同时降低上下文体积。

## 核心方法

- 审计大块章节。
- 用户确认外移范围。
- 完整备份。
- 抽取章节到技能包。
- 自动生成路由索引。
- 验证路径、测试和路由准确率。
- 失败时回滚。

## 边界

- 不做简单文字压缩。
- 身份、核心判断尺、对话方式保留在主 SKILL。
- 修改前必须备份，验证失败不宣布完成。
- 实际结果：2034 行 → 586 行。
